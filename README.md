# CommunityHub Team Project - RentSmart

## The Problem
Searching for a house requires physical searching from house to house, looking at adverts and social media postings. It is slow, tiring, and you still may not find what you want.

## The Solution
RentSmart eases the search by providing results of the types of houses a person wants, in the location they want, with a description of the houses on display and their price. No more moving house to house to ask.

## What RentSmart Does
- For Renters: Search by house type, location, and price — see description, photos, and price before you visit
- For Landlords: Post and manage houses in one place

## Features
- Browse rental listings with photos, price, and location
- Search and filter by house type, location, and price
- View full description of each house
- Landlords can add, edit, and manage listings

## How to Run
1. Clone the repo:
   `git clone https://github.com/SketchAlien/iyf-s12-communityhub.git`
   
3. For frontend:
   - cd frontend
   - npm install
   - npm run dev
     
3. For backend:
   - cd backend
   - npm install
   - npm start
